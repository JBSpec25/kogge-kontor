# Kogge & Kontor

Rundenbasiertes Handelsspiel zur Hansezeit, gebaut fürs Telefon. Du beginnst 1356 in Lübeck mit einer alten Schnigge, handelst zwischen zwölf Hansestädten, wehrst Seeräuber ab und arbeitest dich bis zum Ältermann der Hanse hoch.

## Spielen

Öffne den Link, den du bekommen hast, in Safari (iPhone) oder Chrome (Android).

**Als App auf dem Home-Bildschirm** (empfohlen):

- iPhone: in Safari auf Teilen tippen, dann „Zum Home-Bildschirm“.
- Android: in Chrome im Menü „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Dann startet das Spiel wie eine App, im Vollbild und auch ohne Netz.

## Spielstände

- Das Spiel speichert automatisch, bis zu drei Spielstände, nur auf deinem Gerät. Es gibt kein Konto und keinen Server.
- Safari und die App auf dem Home-Bildschirm haben getrennte Speicher. Spiele am besten immer über das Symbol auf dem Home-Bildschirm.
- **Spielstand umziehen** (neues Telefon, Safari → App): unten auf „Spielstände“ tippen, unter „Auf ein anderes Gerät übertragen“ den Code kopieren und auf dem anderen Gerät dort einfügen.
- Eine Website, die man lange nicht öffnet, kann Safari samt Daten aufräumen. Auf dem Home-Bildschirm passiert das nicht. Wer auf Nummer sicher gehen will, kopiert sich ab und zu den Spielstand-Code.

## Neue Versionen

Neue Versionen kommen von selbst: Wer das Spiel mit Netz öffnet, bekommt die neueste Version. Ohne Netz startet die zuletzt geladene. Alte Spielstände laufen weiter.
